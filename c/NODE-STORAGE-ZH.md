# 节点存储

C 网关使用 SQLite，路径由 `FASTP2P_DATABASE` 指定，默认 `./nodes.sqlite3`，文件权限 0600，使用同步回滚日志。保存节点名、设备身份、主机名、版本/系统、网络地址及首次/最近活动时间。

自动名称优先取系统主机名，规范化后至少 8 位，不足补随机数字。冲突补数字后缀，在事务及唯一约束下分配。设备持久化 128 位随机 DeviceID，重连、重启及网关恢复后沿用名称。唯一范围为同一网关注册表。

在线状态由当前连接计算，重启不会把历史记录误报在线。Web 可搜索和分页查看离线记录。无效身份不能抢占已注册的自动名称。

fastp2p application_id 为 `0x46503250`，schema version 2。旧 C 网关数据库升级时保留记录并更新 application_id，这是数据迁移，不保留旧客户端协议。升级前使用 SQLite backup 备份，回退旧程序必须恢复旧快照。

版本 2 增加管理账号表，保存用户名、独立随机盐、PBKDF2-SHA256 密码哈希及会话签名密钥，不保存 Web 设置的新密码明文。离线记录可在 Web 删除；在线记录受客户端连接表和数据库条件双重保护。
