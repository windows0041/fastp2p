# Sources and dependencies

This independent C implementation follows the control protocol of the Go
reference in `go/gateway`, based on https://github.com/openp2p-cn/gateway-lite.
The upstream MIT license is preserved in LICENSE. Go is not linked or invoked
at runtime; Go clients are used only as interoperability test peers.

CRC64/ISO node IDs, little-endian frames and HMAC-SHA256 TOTP follow the existing
OpenP2P protocol. TOTP is compatible with https://github.com/openp2p-cn/totp; a
unit-test vector was generated by that reference implementation.

System-linked dependencies, not vendored here:

- libwebsockets >= 4.1: https://libwebsockets.org/ — primarily MIT; see the
  distribution copyright file for embedded components.
- OpenSSL >= 3.0: https://www.openssl.org/ — Apache-2.0.
- json-c >= 0.16: https://github.com/json-c/json-c — MIT.

Debian supplies full system-library notices and source packages. Native
packages require the matching distribution runtime libraries; the Docker
image installs those packages with their notices.
